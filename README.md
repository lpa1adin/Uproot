# Uproot

Uproot — приложение для поиска и удаления программ вместе с их возможными остатками. Оно показывает связанные файлы и системные записи, чтобы вы могли проверить найденное и выбрать, что удалить.

Для macOS и Windows есть отдельные версии с родным для системы интерфейсом. Uproot ищет данные в известных расположениях и не обещает найти каждый файл: некоторые программы сохраняют их в произвольных папках или используют общие компоненты.

## Возможности

- **Программы** — список установленных приложений и переход к поиску связанных с ними данных.
- **Следы приложения** — папки, настройки, кэши, контейнеры, журналы и элементы автозапуска на macOS; папки установки, `AppData`, `ProgramData`, ярлыки и системные записи на Windows.
- **Остатки удалённых программ** — поиск папок и файлов, которые могли сохраниться после деинсталляции.
- **Поиск файлов** — ручной поиск по домашней папке, библиотекам или доступным областям диска на macOS.
- **Проверка перед удалением** — найденные пути можно просмотреть и отметить нужные элементы. Uproot защищает системные пути.
- **Корзина** — файлы и папки перемещаются в Корзину, откуда их можно восстановить, пока она не очищена.
- **Штатное удаление Windows-программ** — Uproot запускает деинсталлятор, затем помогает проверить оставшиеся данные.
- **Резервные копии реестра** — перед удалением выбранных записей Windows сохраняет их в `.reg`.
- **Настройки оформления** — темы и параметры интерфейса доступны в самом приложении.

## Установка и запуск

### macOS

Требуется macOS 14 или новее. Установщик создаётся из исходников:

```bash
cd mac
./make-dmg.sh
```

Образ появится в `mac/build/Uproot-1.0.dmg`. Откройте его и перетащите Uproot в папку «Программы».

Можно собрать приложение без установочного образа:

```bash
cd mac
./build.sh
```

Готовое приложение: `mac/build/Uproot.app`.

Локальная сборка подписывается ad-hoc и не проходит нотарификацию Apple. При первом запуске Gatekeeper может предупредить, что разработчика не удалось проверить. В этом случае нажмите Uproot правой кнопкой в папке «Программы» и выберите «Открыть». Для распространения без предупреждения нужны Developer ID и нотарификация Apple.

### Windows

Требуются Windows 10 или Windows 11 и .NET 10 Desktop Runtime. Чтобы собрать приложение, установите .NET 10 SDK и выполните в PowerShell:

```powershell
cd windows\Uproot
dotnet publish -c Release -r win-x64 --self-contained false -o publish
```

Файлы появятся в `windows\Uproot\publish`. Запустите `Uproot.exe`; Windows запросит права администратора. Для Windows-версии готового установщика пока нет.

## Как пользоваться

### Найти и удалить приложение

1. Откройте раздел приложений и выберите программу.
2. Запустите поиск следов. Uproot покажет найденные расположения и категории.
3. Проверьте список и отметьте только те элементы, которые хотите убрать.
4. Подтвердите действие.

На macOS выбранные файлы перемещаются в Корзину. При доступе к защищённым системным данным может понадобиться «Полный доступ к диску» или пароль администратора.

На Windows сначала запускается штатный деинсталлятор. После его завершения проверьте найденные остатки отдельно. Файлы и папки отправляются в Корзину; для записей реестра создаются резервные копии.

### Найти отдельные файлы на macOS

Откройте поиск файлов и выберите область поиска: домашнюю папку, библиотеки или доступные области диска. Проверьте результаты, отметьте нужные элементы и переместите их в Корзину.

## Разрешения и восстановление

### macOS: доступ к файлам

Для поиска в защищённых каталогах включите «Полный доступ к диску» для Uproot в настройках конфиденциальности macOS. Приложение предлагает открыть нужный раздел системных настроек при первом запуске и оставляет управление доступом в настройках Uproot.

После пересборки ad-hoc подписанного приложения macOS может потребовать выдать разрешение заново.

### Windows: резервные копии реестра

Копии сохраняются в `Документы\Uproot\Резервные копии`, в отдельной папке с датой и временем. Чтобы вернуть ключ, откройте нужный `.reg` и подтвердите импорт в Windows.

Резервная копия помогает восстановить сохранённые записи реестра. Она не возвращает удалённые файлы, службы или задания планировщика. Перед подтверждением проверяйте пути и названия: найденные элементы могут относиться к общим компонентам или другим программам.

## Разработка

Для сборки macOS-версии нужен Swift 6 и Xcode Command Line Tools.

| Команда | Что делает |
| --- | --- |
| `cd mac && ./build.sh` | Собирает `Uproot.app` в `mac/build/` |
| `cd mac && ./make-dmg.sh` | Собирает приложение и установочный образ `.dmg` |
| `cd mac && swift test` | Запускает тесты сопоставления, защиты путей, поиска и удаления на тестовых файлах |
| `cd windows\Uproot && dotnet publish -c Release -r win-x64 --self-contained false -o publish` | Собирает Windows-приложение для x64 |

Папки сборки и установочный образ создаются локально и исключены из Git. Для Windows отдельный проект автоматических тестов пока не настроен.

## Ограничения

- Полнота результатов зависит от доступных расположений и системных разрешений.
- Совпадение по имени или издателю не всегда означает, что файл принадлежит только выбранному приложению.
- Очистка Корзины удаляет возможность восстановить перемещённые туда файлы.
- Удаление записей реестра, служб и заданий Windows требует осторожности. Перед подтверждением просматривайте выбранные элементы.
- Uproot не заменяет штатные механизмы восстановления системы и не сохраняет копии всех удаляемых данных.
